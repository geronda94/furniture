# Проектирование корпусной мебели — правила и движок

> Три слоя правил. **Универсальные** (здесь) → **цеховые** (`config.yaml`, per-раскройщик) → **брендовые** (фурнитура: Blum/Hettich/GTV).
> Движок считает деталировку/присадку/раскрой детерминированно; агент применяет правила и проверяет валидатором.

## 1. Деталировка (формулы)

Обозначения: `W` — ширина корпуса, `H` — высота, `D` — глубина, `t` — толщина плиты (16/18), `tb` — толщина ДВП.

| Деталь | Размер (чистовой) | Кол-во | Примечание |
|---|---|---|---|
| Боковина | `D × H` (вкладная крыша) / `D × (H−t)` (накладная) | 2 | передний торец — кромка |
| Крыша / Дно | `(W−2t) × D` (вкладные) / `W × D` (накладная) | 1+1 | |
| Полка съёмная | `(W−2t−3) × (D−20)` | n | зазор 3 мм, отступ 20 мм |
| Полка фиксированная | `(W−2t) × D` | n | |
| Перегородка | `(H−2t) × D` | n | |
| Задняя стенка (ДВП) | `(W−2) × (H−2)` | 1 | набивная, в четверть — иначе |
| Фасад | см. §3 | n | 2 мм по периметру |
| Цоколь | `(W−2t) × h_цок` | 1 | h_цок по умолч. 80 |

**Главное правило:** вкладная деталь = минус 2 толщины (`−2t`). Накладная = в чистовой размер корпуса.

## 2. Кромкование

- Толщины: **0,4 / 1 / 2 мм**. Фасады — 2 мм по периметру; внутренние — видимый передний торец.
- `пильный = чистовой − (кромка_лево + кромка_право)` по X, аналогично по Y.
- Ширина кромки = толщина плиты + 3–4 мм (16 → 19–20).
- Соседние детали утапливаются на толщину кромки (эффект «лесенки»).
- Радиусы: внутр. ≥100, внеш. ≥50 (для 2 мм).

## 3. Зазоры фасадов

- Между соседними фасадами **2–3 мм** (по умолч. 3).
- По бокам 1,5–2 мм; сверху/снизу 1,5–2 мм; от столешницы 4–5 мм.
- Накладной фасад: `H_ф = H − зазор_верх − зазор_низ`;
  `W_ф = (W − 2·зазор_бок − (n−1)·зазор_между) / n`.
- Вкладной фасад = проём − 4 мм.
- ГОСТ 16371: двери ≤2 мм, ящики ≤1,5 мм.

## 4. Присадка (System 32)

- **Шаг 32 мм** ±0,1; **отступ от передней кромки 37 мм** ±0,5; **Ø5 мм** +0,1; глубина **13 мм**.
- Полкодержатели: 37 мм от дна, далее через 32 мм (2 ряда: 37 и `D−37`).
- Глухие отверстия: глубина ≤ `t − 2…3`.
- **Конфирмат 7×50:** торец — пилот Ø5×34; пласть — Ø7 (или Ø8)×13.
- **Минификс (эксцентрик):** Ø15, глубина 12,5, 34 мм от торца; шток Ø8; торец Ø5×12.
- **Шкант:** Ø8, глубина 8–13 мм.
- **Петли:** чашка **Ø35**; от торца фасада 22,5 (Blum) / 22 (Hettich/GTV); крайние 80–100 мм; шаг ≤600 мм.
  Кол-во по высоте: до 900 — 2; до 1600 — 3; до 2000 — 4; до 2400 — 5.
- **Направляющие ящика:** зазор 12,5 (ролик) / 13 (шарик) мм на сторону; скрытые — внутр. ширина − 42; длина ящика = направляющая − 10.

## 5. Раскрой

- Лист ЛДСП **2750×1830**; обрез 12–15 мм по периметру; пропил **3,2–4 мм** (пакетная до 5).
- **Направление текстуры:** боковины и фасады — по высоте.
- Деловой отход 10–20%; мин. заготовки под кромку/присадку.

## 6. Движок

```bash
# пример: шкаф 800×2200×500, 2 двери, 3 полки
python3 scripts/engine.py --w 800 --h 2200 --d 500 --doors 2 --shelves 3 --out ./out
```

Выход в `--out`:
- `parts.csv` / `parts.xlsx` — деталировка (чистовой/пильный, кромка по сторонам, кол-во, текстура);
- `cutting.svg` — схема раскроя по листам (ЛДСП/ДВП отдельно);
- `report.txt` — отчёт валидатора (формат листа, допуски, глухие, петли);
- `parts.json` — машинный формат для Blender/SketchUp.

Конфиг цеха: `--config config.yaml` (листы, пропил, обрез, кромки, бренд фурнитуры). Без него — значения по умолчанию (Blum, 2750×1830, kerf 4, trim 15).

## 7. Валидатор (обязательно)

Движок проверяет и печатает нарушения:
1. деталь ≤ полезного формата листа (`лист − 2·обрез`);
2. зазоры > 0 и в допуске;
3. глубина глухих ≤ `t − 2`;
4. кол-во петель соответствует высоте фасада;
5. детали не отрицательные/не нулевые.

Если валидатор выдал ошибки — **не отдавать заказчику**, сначала устранить.

## 7а. Принятые стандарты (кухня, по умолчанию)

- **Кромка корпуса:** скрытые торцы — без кромки; наружные торцы крайних
  секций — 2 мм; фасады — 2 мм; ящик — верхние торцы боковин и задней стенки.
- **Торец обозначается «ПЕРЕД»** (видимый), а не Л/В/П/Н.
- **Фасады:** авто-деление — дверь ≤600 мм, фасад ящика ≤900 мм.
- **Ящики:** скрытые направляющие (Blum Tandem), зазор 21 мм на сторону.
- **Длинные детали** (цоколь, столешница) — сегментировать по формату листа.
- **Габариты напольного корпуса:** 720×560, цоколь 100, столешница 38.
- **Раскрой:** MaxRects (best short side fit), kerf 4, обрез 15.

## 8. Что НЕ кодифицировано (нужен домен)

- какой торец «передний» для нестандартных деталей;
- направление текстуры на косых/радиусных деталях;
- присадка под конкретную модель фурнитуры (см. каталог бренда);
- ограничения конкретного цеха (радиусы, мин. детали) — в `config.yaml`.
