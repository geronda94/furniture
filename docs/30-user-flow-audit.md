# 30 — Аудит пользовательского пути «от комнаты до проекта»

Дата: 2026-10-29. Цель — чтобы человек **без опыта планировки** за 5–7 минут
получил готовый к исполнению проект: деталировку, смету, раскрой, присадку,
фурнитуру и крепёж.

## 1. Целевой путь (после правок)

1. **Меню → Быстрый старт.**
2. Ввести комнату: Д × Г × В, толщина стен.
3. Добавить окна/двери (стена, отступ, ширина) и розетки/выключатели
   (стена, отступ, высота).
4. Выбрать сценарий: **Кухня** или **Гардероб/шкаф**, стену и высоту шкафа.
5. «Создать проект» → сервер расставляет модули по `docs/20`, считает
   деталировку/смету/раскрой и открывает проект.
6. **Меню → Готовый проект** — сводка: модули, детали, листы, КПД,
   отверстия, смета, фурнитура; CSV: отверстия, детали, раскрой, фурнитура;
   КП и печать; JSON.

## 2. Что проверено и исправлено

| Находка | Было | Стало |
|---|---|---|
| Нет быстрого пути | нужно вручную создавать проект, стены, модули | мастер `QuickStart` + `POST /api/quickstart` |
| Нет единой сводки | смета и раскрой по модулям, вручную | панель «Готовый проект» |
| Раскрой без координат | `sheets` отдавал только материал/кол-во | в ответе `placements` (x/y/w/h/rot), CSV раскроя |
| Нет выгрузки присадки | только экран карты | CSV всех отверстий (X/Y/Ø/глубина/фурнитура) |
| Нет перечня фурнитуры одним файлом | по модулям | CSV фурнитуры и крепежа |
| Стандарты не проверялись | только геометрия/зазоры | `standards.py` (ГОСТ/EN), коды `std-*` |
| Демо нарушали ГОСТ | остров 938 мм, ящик 1000 мм, полки 1668 мм | исправлено, демо 0/0 |
| Библиотека без мягкой мебели | 17 объектов без категорий | 29 объектов, субкатегории, диваны/кровати/кресла |

Серверный генератор:
- кухня: ряд вплотную, мойка/ПММ/варочная/тумбы, пенал-холодильник,
  навесные над рабочими секциями, вырезы мойки и варочной;
- гардероб: секции по 600 мм, стойки при пролёте >1000, полки, высота 1800–2700;
- двери на соседних стенах учитываются (отступ 900 мм), окна — по высоте;
- розетки/выключатели — `wallItems`;
- результат сразу проходит расстановку и ГОСТ/EN (иначе 422, проект не сохраняется).

## 4. Остаточные разрывы (приоритет)

1. ✅ **Раскрой проекта сделан.** `POST /api/projects/{id}/cutting` собирает
   детали всех модулей и укладывает их вместе: demo-apartment — 55 листов
   (по модулям, КПД 54.6 %) → **25 листов, КПД 80.7 %**. UI показывает
   общий раскрой и выгружает CSV с координатами.
2. ✅ **Выгрузки для цеха сделаны:** «Готовый проект» → XLSX (детали,
   раскрой, присадка, фурнитура, смета), DXF деталей, SVG раскроя.
   CSV (отверстия/детали/раскрой/фурнитура) — там же.
3. ✅ **Серверный PDF КП сделан:** `POST /api/projects/{id}/quote.pdf`
   (reportlab, DejaVu для кириллицы, бренд из `specs/branding.yaml`);
   кнопка «PDF КП» в «Готовом проекте».
4. ✅ **Розетки/выключатели перетаскиваются** по развёртке стены
   (`WallView`, тест `e2e/wallitems.mjs`).
5. ✅ **Г-образная комната** в мастере (вырез, 6 стен, проёмы/мебель).
6. ✅ **Вытяжка и антресоли** добавлены в быстрый старт; угловой модуль
   900×900 — в библиотеке (радиусные фасады пока не моделируются).
7. **Прочность/устойчивость:** добавлен расчёт энергии опрокидывания
   (EN 14749, порог 60 Н·м) и предупреждение о креплении; физические
   стенды — отдельно.
8. **Реальные замеры на телефоне** — протокол `docs/31-device-checklist.md`.
