# 06 — 3D-пайплайн (Blender)

## Поток

```
kitchen.py → scene3d.json → blender_build.py → .blend + рендеры + видео
```

`scene3d.json` — плоский список коробок: `{name, x, y, z, sx, sy, sz, kind, sec, ...}`
плюс механика: у дверей `hinge`, у ящиков `drawer_id`/`open`.

## Координаты (мм)

- **X** — длина (0…L)
- **Y** — глубина (**0 = фасад**, растёт вглубь)
- **Z** — вверх (0 = пол)
- В Blender — метры (÷1000).

## Сборка (`tools/blender_build.py`)

1. **Каждый элемент — отдельный объект.** Ничего не склеивать по материалу.
   Имена: `Крыша·3`, `Боковина Л·1`, `Дверь·2`, `Фасад ящик·4`, `Ящик·2`, `Ножка·1`.
2. **Двери** — объект с началом координат на оси петли (край), вращение по Z.
3. **Ящики** — фасад + короб (короб — дочерний к фасаду), выкат по −Y.
4. **Ручки** — отдельные объекты, привязаны к двери/ящику.
5. **Материалы:** ЛДСП, фасад, столешница, цоколь, ДВП, ящик, ручка, ножка.
   `material.diffuse_color` задаётся (для Workbench).

## Режимы рендера

| Режим | Что | Движок |
|---|---|---|
| `stills` | 4 статичных вида (закрыто/открыто/спереди/торец) | Cycles |
| `anim` | открытие всех дверей/ящиков | EEVEE |
| `tour` | камера едет вдоль, двери/ящики открываются по очереди | Workbench |
| `norender` | только собрать `.blend` | — |

## Анимация и ракурсы (правила)

1. **Открывать по очереди, а не всё сразу.** Каждый элемент открывается, когда он
   «в фокусе» камеры. Порядок — слева направо по X-координате
   (`open_frame(x) = 1 + (x/L)·(N − длит.открытия)`).
2. **Лимиты движения.** Дверь — не более ±95°; ящик — выкат ≤ (длина направляющей − запас),
   ~420 мм. За пределы лимита не выходит.
3. **Блокировка лишних осей.** Дверь: `LIMIT_ROTATION` (X и Y = 0, Z в диапазоне 0…угол).
   Ящик: движение только по −Y.
4. **Без «перелёта».** Ключи — `AUTO_CLAMPED` (Bezier без overshoot).
5. **Красивые ракурсы.** Камера ведёт взгляд: 3/4, чуть сверху, цель «ведёт» на
   открывающуюся секцию. Не снимать всё одновременно планом «в лоб».

Кадры: 1 — закрыто; `N_TOUR` (220) — всё открыто; между — по очереди.

## Запуск

```bash
blender -b -P tools/blender_build.py -- projects/<имя>/scene3d.json projects/<имя>/renders tour
```

## Особенности Blender 5.x

- Движки: `BLENDER_EEVEE`, `BLENDER_WORKBENCH`, `CYCLES` (не `_NEXT`).
- Видео: сначала `image_settings.media_type = 'VIDEO'`, затем `file_format='FFMPEG'`.
- Экшены «слотовые»: `.fcurves` нет — идти через `layers→strips→channelbags`.
- Snap-Blender не стартует из оболочки → рендер headless на сервере.
