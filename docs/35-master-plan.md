## 9. Правила работы

1. Одна сессия — один пункт; рефакторинг параллельно не тащить.
2. До: `python3 tests/golden.py` + профильный тест. После: профильные тесты,
   `tsc --noEmit`, `npm run build`, при изменениях прода — `tools/deploy.sh`.
3. Не выдумывать размеры; не менять `specs/` цены; golden — только с причиной.
4. Всё необратимое (деньги, заказ раскроя) — только с подтверждением.
5. Коммит — по просьбе; один коммит = один пункт.
6. Если ИИ «тупит» — сузить до одного файла и одного теста.
