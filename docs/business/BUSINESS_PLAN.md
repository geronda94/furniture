## 1. Резюме

**Furniture** — детерминированный движок производственного конфигурирования.
Превращает размеры в проверяемую деталировку, раскрой, присадку, смету,
BOM, DXF/SVG/GLB и 3D-визуализацию. На выходе — не «красивая картинка»,
а производственный пакет, которым цех/застройщик/бренд работает без переделок.

**Проблема.** Малые цеха, застройщики, бренды теряют деньги на ошибках
раскроя, несовпадении каталогов, ручной перерисовке спецификаций.
PRO100/Базис — тяжёлые, десктопные; Planner 5D/Roomle — только визуал,
нет производственного выхода.

**Решение.** Один детерминированный ядро (Python):
размеры → деталировка → кромка → присадка → раскрой → BOM/DXF/SVG/GLB → смета → 3D.
Браузер — для конфигурации, Python — для правил и расчёта. Одинаковый вход
→ одинаковый результат. Правила — исполняемый код и тесты.

**Текущее состояние.** Рабочий прототип (TRL 5–6): движок, веб-конструктор
(Vue 3 + Babylon), API, тесты (golden/geometry/features), контент-пайплайн
(Blender). Нет выручки, клиентов, CRM, биллинга, мультитенантности.

**Стратегия — 5 треков на 18 месяцев → €125k/мес:**

1. **Сервисы на текущем движке (месяц 0)** — пилоты €300 цехам Бухареста,
   контент-услуги брендам, CAD→раскрой сервис. Плато €5k/мес.
2. **Форк под застройщиков (месяц 3)** — конфигуратор квартир/виджет для
   off-plan продаж. Production-output: BOM, цены, валидные финиши, DXF/IFC.
   Цель €25k/мес.
3. **BIM-бюро (месяц 5)** — параметрические семьи Revit + веб-конфигуратор
   финишей для застройщиков. Партнёрство с BIM-бюро. Цель €25k/мес.
4. **Фабрика оцифровки (месяц 6)** — каталог→конфигуратор, CAD→BIM,
   производственные модели. Стандартизированный пайплайн. Цель €45k/мес.
5. **White-label платформа (месяц 12)** — self-serve конфигуратор SaaS
   для производителей 20-500 SKU. Цель €25k/мес.

**Итого 18 мес: €125k/мес с 4 операторами.**

**Рынки удалённой работы (3 направления параллельно):**
- **Турция** — B2B порталы для крупных заводов (экспорт в ЕС). Setup €3-5k +
  €300-500/мес.
- **Бухарест** — виджеты/пилоты для малых цехов. €300 пилот + €100/мес.
- **Грузия** — Export Pack для маркетплейсов (Wayfair, US). €2-4k за 50 SKU.

**Запрос гранта/инвестиций:** €40–70k на 6–12 месяцев. Цели: 3–5 платящих
партнёров, 10+ пилотов, доказанная юнит-экономика, white-label пилот,
контент-машина на 2–3 языка.

## 2. Проблема

### 2.1. Для мебельного цеха
- Проект приходит рисунком, фото, PDF, SketchUp — замеры перепроверяют вручную.
- Деталировка и раскрой в разных файлах, кромка/волокно теряются.
- Фурнитура «на глаз», присадка не сходится.
- Ошибка в одной детали = 200–500 евро убытка, переделка, сорванный срок.
- Клиент не понимает чертёж — согласование затягивается.

### 2.2. Для застройщика (off-plan продажи)
- Покупатель хочет выбрать финиши (плитка, ламинат, сантехника, кухня)
  и видеть цену в реальном времени.
- Менеджеры собирают пакеты финишей вручную — дни работы, ошибки в BOM.
- Нет валидного пакета для закупки/производства кухонь-гардеробов.
- Нет виджета на сайте — теряют горячих покупателей.

### 2.3. Для бренда/производителя (экспорт, маркетплейсы)
- Нет цифровых каталогов для Wayfair, ManoMano, европейских дилеров.
- Покупатели просят GLB/USDZ, точные габариты, HS-коды, BOM на английском.
- Ручная подготовка каталога = месяцы работы, ошибки в данных.

### 2.4. Почему это больно
Средний чек кухни/шкафа/квартиры — тысячи евро. Ошибка в раскрое/BOM
съедает маржу заказа. Для малого цеха — прямой убыток. Для застройщика —
потеря покупателя. Для бренда — упущенный канал сбыта.

## 3. Решение

### 3.1. Продукт — единый production kernel

Веб-конструктор + API, которые:
1. Принимают размеры комнаты/модуля/квартиры.
2. Собирают корпус: двери, ящики, полки, перегородки, задник, крыша,
   царги, цоколь, столешница, вырезы, финишные материалы.
3. Считают деталировку, кромку, присадку System 32, раскрой MaxRects,
   BOM, DXF/SVG/GLB/IFC, смету.
4. Показывают 3D (Babylon.js) и 2.5D, открывают двери/ящики, дают размеры.
5. Экспортируют JSON/CSV/SVG/DXF/GLB/IFC/PDF для производства и закупки.

### 3.2. Ключевое отличие

**Детерминированный движок — источник истины.** ИИ не «считает в голове»,
а вызывает код. Одинаковый вход → одинаковый результат. Правила —
исполняемый код и тесты (golden/geometry/features), а не советы в чате.

**Production-output, а не только 3D:** раскрой, присадка, BOM, валидные
комбинации (rules engine), DXF для CNC, IFC для BIM — это то, за что
платит цех/застройщик/бренд прямо сейчас.

### 3.3. Что уже есть
- Python-движок (`tools/furniture_core`): деталировка, кромка, System 32,
  MaxRects, DXF/SVG/GLB, `scene3d.json`, смета, валидатор.
- Веб: Vue 3 + Vite, Babylon.js 3D, 2.5D план, комната, стены, проёмы,
  модули, фасады/ящики/полки, материалы, текстуры, drag&drop, коллизии,
  поворот, группы, undo, автосейв, экспорт.
- API: каталог, материалы, цех, фурнитура, solve, validate, AI-guide,
  проекты, summary, actions.
- Тесты: golden (5 эталонов), geometry (9 конфигураций, 0 пересечений),
  features (18 проверок), tsc, build.
- Контент-пайплайн: Blender (`tools/blender_build.py`), рендеры, видео,
  превью, карточки.

### 3.4. Три слоя продукта

| Слой | Что это | Роль |
|---|---|---|
| **Ядро** | конструктор + деталировка/раскрой/смета | моат, производственный результат |
| **Контент** | 3D-каталоги, рендеры, видео | канал, доверие, быстрый кэш |
| **Интеграция** | сайт/виджет + каталог + лиды | B2B-упаковка, recurring |

Контент без ядра — агентство услуг. Ядро без контента — продукт, который
никто не видит. Интеграция без ядра — просто сайт. Вместе — продукт.

### 3.5. Чего пока нет
- Многопользовательность и облако (мультитенантность — Трек 5).
- CRM/передача лидов (встроим в виджет/платформу).
- Платежи (Stripe Connect — Трек 5).
- Полный каталог фурнитуры Blum/Hettich (подключаем по запросу).
- Угловые/радиусные модули, сушка, встроенная техника (roadmap).
- Версионирование проектов, импорт SketchUp/IFC, CNC-постпроцессор.
- Кнопка рендера из веба (Blender pipeline есть, кнопки нет).

## 4. Почему сейчас

1. **AI удешевил контент и код** — 3D-каталоги, видео, переводы, парсинг
   каталогов делаются полуавтоматически.
2. **Цехи и застройщики digitize-ятся** — маркетплейсы и онлайн-заказы
   давят на скорость и точность.
2. **Клиенты привыкли к 3D** — Planner 5D/IKEA Kreativ научили рынок.
3. **Ниша пуста** — между «визуальным планировщиком» и «тяжёлым CAD»
   нет веб-инструмента с производственным выходом для малого бизнеса.
4. **Румыния/Турция/Грузия — доступные полигоны** — ЕС/экспорт, средняя
   покупательная способность, много стройки/ремонта, низкая конкуренция
   в production-grade конфигураторах.

## 5. Рынок

### 5.1. Румыния (база операций)
- Потребительский рынок мебели: ~€2,1 млрд (2025), рост ~5% г/г.
- Розница: ~€1,55 млрд. Производство: ~€3,2 млрд.
- Новые квартиры: 59 тыс. (2025), Бухарест-Илфов — главный кластер.
- Кухни ~20%, корпусная мебель ~45%. Онлайн растёт.
- Конкуренты: IKEA, Mobexpert, XXXLutz, локальные, премиум (Nolte).

### 5.2. Турция (B2B экспорт)
- Крупное производство (Istanbul, Ankara, Kayseri, Bursa).
- Экспорт в ЕС, Ближний Восток, Африка. Нужен B2B-канал для дилеров.
- Конкуренты: локальные ERP/CAD, нет удобного white-label B2B портала.

### 5.3. Грузия (экспорт в ЕС/US)
- Заводы в Тбилиси/Кутаиси/Рустави. Экспорт в Европу, США, Израиль.
- Нужен Export Pack для Wayfair, US-маркетплейсов, европейских дистрибуторов.

### 5.4. Конфигураторы застройщиков (соседние рынки)
- Болгария, Молдова, Венгрия, Турция — похожая логика, меньше конкуренции.
- Рынок off-plan конфигураторов: youconfig, MaverickFrame, Beyond Visual,
  Aperex, Divergent, Vinode, Habiteo, R2U — цены €5-50k/проект + recurring.
- Наш козырь: production-output (BOM, цены, DXF/IFC), а не только визуал.

### 5.5. Целевые сегменты

**B2B (главный):**
- Малые/средние мебельные цеха (5–50 чел.) — Румыния, Турция, Грузия.
- Застройщики/девелоперы (off-plan продажи) — Румыния, Болгария, Турция.
- Бренды/производители для экспорта/маркетплейсов — Турция, Грузия.
- BIM-бюро/архитекторы — параметрические семьи + конфигуратор.

**Партнёры:** цеха-производители, поставщики фурнитуры/материалов,
агентства для reseller-модели.

## 6. Бизнес-модель — 5 треков

### 6.1. Трек 1: Сервисы на текущем движке (месяц 0)
**Что продаём:** пилоты цехам («проект кухни за 2 часа — 3D, раскрой,
смета за €300»), контент-услуги брендам (рендеры/видео €500-800),
CAD→раскрой сервис цехам с CNC (€50/лист).
**Целевой рынок:** Бухарест (малые цехи), бренды (Mobexpert, XXXLutz).
**Цены:** пилот €300, контент €500-800/видео, раскрой €50/лист.
**Планка:** €5k/мес (плато), передача подрядчику за €400-600/мес.

### 6.2. Трек 2: Форк под застройщиков (месяц 3)
**Продукт:** виджет конфигуратора квартиры на сайте застройщика.
Покупатель выбирает финиши (плитка, ламинат, сантехника, кухонные модули),
видит цену в реальном времени. Застройщик получает: валидный пакет финишей,
BOM на закупку, IFC для BIM, DXF для кухонь/гардеробов.
**Конкуренты:** youconfig, MaverickFrame, Beyond Visual, Aperex, Divergent,
Vinode, Habiteo, R2U — выдают только визуал.
**Наш козырь:** production-output (BOM, цены, валидные комбо, DXF/IFC).
**MVP:** каталог финишей с ценовыми тирами, поэтажный конфигуратор,
админка застройщика, выводы PDF/Excel/IFC.
**Пилот:** 1 румынский застройщик, 5 типов квартир, 3 мес бесплатно.
**Цены:** setup €5k + €500/мес + €50/лид. Цель 18 мес: €25k/мес.
**Нужен:** 1 dev.

### 6.3. Трек 3: BIM-бюро (месяц 5)
**Продукт:** параметрические семьи Revit (LOD 300) + веб-конфигуратор
финишей для отдела продаж застройщика. Партнёрство: BIM-бюро делает Revit,
мы — веб-конфигуратор + правила.
**Пакет:** типовой этаж (5 типов квартир) + веб-конфигуратор + BOM + IFC.
**Цена:** €8-15k за пакет. Цель 18 мес: €25k/мес.
**Нужен:** 1 архитектор + партнёр-бюро.

### 6.4. Трек 4: Фабрика оцифровки (месяц 6)
**Продукт:** стандартизированный пайплайн: PDF/DWG каталог → парсер →
rules engine → движок → 3D (GLB/USDZ), 2D (SVG/DXF), BOM (CSV),
раскрой (SVG), цены (JSON) → автотесты + QA → выдача: веб-вьювер,
пакет файлов, API.
**Продукты и цены:**
- Оцифровка каталога (50 SKU) — €3k, маржа 90%.
- CAD→конфигуратор — €10k.
- BIM-библиотека семейств — €20k.
- Единичная производственная модель — €1k.
**Unit economics:** при 50% загрузке оператора — €45k выручка, €4.5k
затраты, €40.5k валовая маржа.
**Нужен:** 1 оператор (младший архитектор/инженер €800-1200/мес) к мес. 6,
senior QA к мес. 9.

### 6.5. Трек 5: White-label платформа (месяц 12)
**Проблема рынка:** Roomle/Planner5D — €850-1450/мес, enterprise sales,
3-6 мес онбординг. Closetforge — £79-199, только гардеробы. 3dconfigurator.dev
— $8-28k разово, кастомная разработка.
**Пробел:** €100-300/мес, self-serve, production-output, 1 неделя онбординг
для производителей 20-500 SKU.
**MVP:** multi-tenant, CSV→Params импорт, визуальный rule builder,
BOM/DXF/SVG экспорт, iframe embed + lead webhook, аналитика, Stripe Connect.
**Цены:** Starter €500 setup + €99/мес + €15/лид (20-50 SKU);
Pro €1500 setup + €299/мес + €10/лид (100-500 SKU);
Enterprise €5k setup + €799/мес + €5/лид (500+ SKU).
**Unit economics:** CAC €500, LTV Pro 24 мес = €5740, LTV/CAC 11.5x,
payback 2 мес. Цель: 20 платящих к мес. 18, 100 к мес. 24 (€25k MRR).
**Нужен:** 1 full-stack dev.

### 6.6. Продуктовые упаковки поверх треков

Один и тот же kernel продаётся тремя упаковками:

**Сайт + конструктор + лиды (главный B2B-оффер).** Мебельному
магазину/студии продаём не «софт», а готовый канал:
- сайт/витрина под их бренд;
- каталог их SKU;
- конструктор;
- заявки в их CRM/почту;
- 3D/PDF-КП;
- аналитика.

Цена: **setup €2–10k + €300–1 500/мес** или **€20–40/лид**. Это выше, чем
«виджет», и использует весь MVP.

**Виджет на существующий сайт.** Если сайт уже есть — встраиваем iframe/JS:
брендинг, каталог, конструктор, лиды, без переезда сайта.
Цена: **setup €1–5k + €200–800/мес** или за лид.

**White-label для сетей.** Сеть/франшиза получает несколько точек/городов,
единый каталог, роли, лиды по точкам, брендинг.
Цена: **€5–15k setup + €1–3k/мес** (позже).

**Модель:** 50% предоплата, остаток по приёмке. Хостинг вьювера €200-300/мес.
**Продажи:** LinkedIn → Export Manager/CEO. Демо на georgia.demo.
**Цель 6 мес:** 5-10 заводов = €10-20k разово + €1-2k MRR.

## 8. Go-to-market (обновлённый)

### 8.1. Принцип
**Не строить SaaS первым.** Продаём сервисы и пилоты сейчас (Трек 1),
параллельно валидируем 3 рынка удалённой работы, на этой основе строим
продуктовые треки 2-5.

### 8.2. Каналы по рынкам
- **Бухарест (цехи):** Вибер/звонки → демо Zoom → пилот €300 → виджет €100/мес.
- **Турция (заводы):** LinkedIn Sales Navigator → Export Manager → демо
  turkey.demo → пилот 3 мес бесплатно → платный setup.
- **Грузия (экспорт):** LinkedIn/Email → Export Manager/CEO → демо
  georgia.demo → Export Pack 50% предоплата.
- **Застройщики (Румыния/Болгария):** LinkedIn/отраслевые события →
  Sales/Development Director → пилот 3 мес бесплатно → платный пакет.
- **BIM-бюро:** прямые контакты, партнёрство 50/50 на пилоте.

### 8.3. Воронка (реалистичная)
- Аутрич 20 контактов → 5-8 демо → 2-3 пилота → 1-2 платящих.
- Контент (Reels/Shorts из пилотов) → ретаргетинг €5/день → входящие.
- Рефералы от пилотов → новые цехи/застройщики без cold outreach.

## 15. Вывод

Furniture — не «ещё один 3D-редактор». Это **production-grade конфигуратор**
с детерминированным ядром, который становится мостом между клиентом,
дизайном, застройщиком и цехом. У проекта работающий прототип, тесты,
документация; не хватает коммерческого пилота, партнёров и фокуса на
трех рынках удалённой работы.

**Стратегия:** Бухарест (Трек 1) → параллельно Турция/Грузия (удалёнка) →
Трек 2 (застройщики) → Трек 3 (BIM) → Трек 4 (фабрика оцифровки) →
Трек 5 (платформа). Деньги — сначала сервисы/пилоты (Трек 1 + 3 рынка),
потом продуктовые треки 2-4, потом платформа Трек 5.

Грант/инвестиции — не на «идею», а на доведение прототипа до пилотов с
реальными застройщиками/заводами, запуск контент-машины на 3 рынка,
доказательство юнит-экономики каждого трека.
