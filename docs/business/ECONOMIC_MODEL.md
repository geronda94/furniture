# Экономическая модель Furniture v2.0

Дата: 2026-10-25. Все цифры — **гипотезы для проверки в пилотах**, не прогноз.
Обновлено после deep-research рынков Турция/Румыния/Грузия/Застройщики/BIM
и валидации 5-трековой стратегии.

> **Важно о сценариях.** Консолидированная P&L в разделе 4 (€125k выручки к
> месяцу 18) — это **агрессивный сценарий при одновременном исполнении всех
> 5 треков** (B2C YouTube + застройщики + BIM + оцифровка + платформа) и
> найме 4 операторов. **Реалистичный B2C-only сценарий** (только YouTube-лиды
> на кухни/гардеробы, без B2B-треков) — **€10-15k чистыми к 18 месяцу**;
> см. `B2C_YOUTUBE_STRATEGY.md`. Не путать эти два прогноза.

---

## 1. Принципы

1. **Сначала — деньги сейчас** (сервисы/пилоты/контент), потом — подписка/SaaS.
2. **Не строить SaaS до 3 платящих пилотов** в каждом треке.
3. **Считаем не «просмотры», а лиды, партнёров, маржу, cash flow.**
4. **Единая P&L модель** — все треки в одной таблице, никаких изолированных
   сценариев. Зарплата фаундера, налоги, эквайринг — внутри.
5. **Каждая цифра проверяется в пилоте** до масштабирования трека.

## 3. Юнит-экономика по трекам (гипотезы для пилотов)

### 3.1. Трек 1: Сервисы (Бухарест)

| Параметр | Значение |
|----------|----------|
| Пилот цена | €300 |
| Время доставки | 2 часа (фаундер) → 4 часа (оператор) |
| Виджет MRR | €100/мес |
| Контент/видео | €500-800 (маржа 60-70%) |
| CAC (cold outreach) | €50-100 (время фаундера) |
| Конверсия outreach→пилот | 10-15% (20 звонков → 2-3 пилота) |
| Плато выручки | €5k/мес (фаундер + 1 оператор) |

**Break-even Трек 1:** 2 пилота/мес = €600 покрывают оператора (€400-600).
Цель: 10 цехов на виджете = €1k MRR + 4 пилота/мес = €1.2k = €2.2k/мес
чистой маржи после зарплаты оператора.

### 3.2. Трек 2: Застройщики

| Параметр | Значение |
|----------|----------|
| Setup fee | €5k (однократно) |
| MRR | €500/мес |
| Per lead | €50 |
| Ожидаемые лиды/мес/застройщик | 20-50 |
| CAC (LinkedIn + демо) | €1.5-2k (время фаундера + dev) |
| Цикл сделки | 1-3 мес |
| Churn (оценка) | 10-15%/год (застройщик не уходит легко) |
| LTV (3 года) | €500 × 36 × 0.85 = €15.3k |
| LTV/CAC | 7-10x |
| Payback | 3-4 мес |

**Break-even Трек 2:** 3 застройщика = €1.5k setup + €1.5k MRR = покрывает
dev-контракт (€2-3k/мес) к месяцу 6.

### 3.3. Трек 3: BIM-бюро

| Параметр | Значение |
|----------|----------|
| Пакет цена | €8-15k (50/50 с бюро → €4-7.5k нам) |
| Проектов/мес/бюро | 1-2 |
| CAC (партнёрство) | Низкое (warm intro) |
| Маржа | 80%+ (только архитектор + конфиг) |
| Цель | 2 бюро × 1.5 проектов/мес = €12-22k/мес |

### 3.4. Трек 4: Оцифровка

| Продукт | Цена | Стоимость (оператор 1ч + QA 0.5ч) | Маржа | Ёмкость/мес (1 опер.) |
|---------|------|-----------------------------------|-------|----------------------|
| Каталог 50 SKU | €3k | €150 | 95% | 10 |
| CAD→конфиг | €10k | €500 | 95% | 3 |
| BIM-библиотека | €20k | €1k | 95% | 2 |
| Единичная модель | €1k | €50 | 95% | 50 |

**При 50% загрузки:** 5 каталогов + 1 CAD + 1 BIM + 25 моделей =
€15k + €10k + €20k + €25k = **€70k выручка**, €7k затраты = **€63k маржа**.
Реалистично к месяцу 9: **€40-45k/мес выручка, €38-40k маржа**.
Оператор €1.2k + Senior QA €2k = €3.2k затраты на людях.

| План | Setup | MRR | Per Lead | Целевой клиент | CAC | Churn/мес | LTV (24 мес) | Payback |

## 10. Вывод

Экономика работает **при условии исполнения гейтов G1-G4 к месяцу 6**.
Ключевые драйверы:
1. **Трек 1 даёт кэшфлоу с дня 1** — покрывает операционку, financеет dev.
2. **Трек 2 даёт крупные setup fees** — финансирует dev Трек 2 и Трек 5.
3. **Трек 4 — главная маржинальная машина** — 90%+ маржа, линейная
   масштабируемость через найм операторов.
4. **Трек 5 — долгосрочный мультипликатор** — запускается на деньгах
   Треков 1-4, не требует внешних инвестиций.

**Риск-моделирование:** при провале 1-2 треков остальные покрывают
burn rate. При провале Трек 1 — фоллбэк на чистый контент/аутсорс.
При провале Трек 2 — фокус на Трек 3+4. При провале Трек 4 — ручная
оцифровка силами архитекторов Трека 3.

Грант €40-70k достаточно для 12-месячного ранвея до кэф-позитивности
(мес. 6-7) и запуска Трек 5. После месяца 12 — самодостаточность,
масштабирование за счёт реинвестирования EBITDA.
