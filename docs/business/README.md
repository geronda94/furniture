# Business documentation — Furniture

Эта папка — **только бизнес**. Технические документы проекта лежат в
`docs/01…16`, `specs/`, `tools/`, `apps/`. Здесь нет кода, API и правил
конструирования.

Дата снимка: 2026-10-24.

## Документы

| Файл | Для чего |
|---|---|
| `BUSINESS_PLAN.md` | бизнес-план: проблема, продукт, рынок, модель, GTM, роадмап, риски |
| `ECONOMIC_MODEL.md` | экономическая модель: цены, юнит-экономика, сценарии, break-even |
| `MARKET_RESEARCH.md` | конкуренты, YouTube, Россия/СНГ, данные и источники |
| `GTM_PLAYBOOK.md` | механизмы запуска с низкими трудозатратами, 30/60/90 |
| `CONTENT_ENGINE.md` | полуавтоматический мультиязычный контент-конвейер |
| `WHITE_LABEL_SAAS.md` | детальный разбор white-label SaaS + лид-роутинг |

## Как использовать

- **Эксперту/грантовому специалисту:** начать с `BUSINESS_PLAN.md`, затем
  `ECONOMIC_MODEL.md`, `MARKET_RESEARCH.md`.
- **ИИ-агенту:** читать `BUSINESS_PLAN.md` + `ECONOMIC_MODEL.md`, не смешивать
  с техническими `docs/`.
- **Для инвестора:** `BUSINESS_PLAN.md` → `ECONOMIC_MODEL.md` → `GTM_PLAYBOOK.md`.
- **Для запуска:** `GTM_PLAYBOOK.md` → `CONTENT_ENGINE.md`.

## Принцип

Бизнес-документы описывают **продукт, рынок и деньги**. Технические детали —
в `docs/13-editor-state.md`, `docs/12-web-constructor.md`, `docs/15-roadmap.md`,
`docs/16-materials-pricing.md`.

Текущее состояние продукта: **рабочий прототип**, не промышленная система.
В документах это указано явно, без завышенных обещаний.
