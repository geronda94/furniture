## Как использовать

- **Для запуска воронки (сейчас):** `B2C_YOUTUBE_STRATEGY.md` →
  `FAST_MONEY_PLAN.md`.
- **Эксперту/грантовому специалисту:** `GRANT_DOSSIER.md` →
  `BUSINESS_PLAN.md` → `ECONOMIC_MODEL.md` → `MARKET_RESEARCH.md`.
- **ИИ-агенту:** читать `BUSINESS_PLAN.md` + `B2C_YOUTUBE_STRATEGY.md` +
  `ECONOMIC_MODEL.md`, не смешивать с техническими `docs/`.
- **Для инвестора:** `BUSINESS_PLAN.md` → `ECONOMIC_MODEL.md` →
  `STRATEGY_EXPANSION.md`.
- **Для B2B (заводы/BIM/оцифровка):** `STRATEGY_EXPANSION.md` →
  `WHITE_LABEL_SAAS.md`.

## Ключевые решения (2026-10-25)

1. **Фокус — B2C:** YouTube продаёт заказчикам кухни/гардеробы, не цехам.
2. **Заводы/цехи — отдельный трек без контента:** они сами заинтересованы,
   подрядчиков находим напрямую.
3. **Замерщика нет:** цех/бригада замеряет сама, ты передаёшь лид с
   фото/видео/планом.
4. **Реалистичный прогноз:** €10-15k чистыми к 18 мес (не €500k).
5. **Рынки по порядку:** Румыния → Казахстан → Грузия.
6. **Пайплайн контента:** AI → конструктор → Blender → видео, 45 мин/ролик.

## Принцип

Бизнес-документы описывают **продукт, рынок и деньги**. Технические детали —
в `docs/13-editor-state.md`, `docs/12-web-constructor.md`, `docs/15-roadmap.md`,
`docs/16-materials-pricing.md`.

Текущее состояние продукта: **рабочий прототип**, не промышленная система.
В документах это указано явно, без завышенных обещаний.
