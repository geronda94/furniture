# 44 — Импорт планов: PDF, изображения, DXF, SVG

Дата: 2026-11-03. Связано: `docs/42-ai-integration.md`,
`docs/43-ai-chat-full-control.md`.

## 1. Что умеет

Человек прикрепляет план в чате (📎) — приложение читает файл, показывает
превью и по возможности достаёт комнату: контур, проёмы, перегородки.
Дальше можно одной кнопкой создать **новый проект по плану** или (если
проект пустой) применить комнату в текущий.

| Формат | Что извлекаем | Без vision-модели |
|---|---|---|
| PDF | текст всех страниц, размеры (`4200 x 3100`), рендер страницы | да: контур по размерам из текста |
| PNG/JPG/WEBP/BMP/TIFF | превью, размеры картинки | нет: показываем превью и просим размеры |
| DXF | отрезки/полилинии, единицы `$INSUNITS`, контур по замкнутой полилинии | да |
| SVG | полигоны/линии/rect, `viewBox`/`width`, контур по крупнейшему полигону | да |
| DWG | не читаем напрямую — сохраните как DXF или PDF | — |

Ограничения: файл ≤ 25 МБ; PDF — одна страница (по умолчанию первая,
поле `page`); SVG с `transform` не разворачиваем; толщины стен и проёмы
из SVG/DXF не угадываем (только контур); фото/скан без vision не
распознаётся.

## 2. API

```
POST /api/projects/{pid}/plan   (multipart)
  file: PDF | PNG/JPG/WEBP/BMP/TIFF | DXF | SVG
  page: номер страницы PDF (1-based, по умолчанию 1)
```

Ответ `furniture/plan-import@1`:

```json
{
  "kind": "pdf|image|dxf|svg",
  "filename": "plan.pdf",
  "preview": "data:image/jpeg;base64,...",
  "pages": 1,
  "page_mm": {"w": 297, "h": 210},
  "text": "текстовый слой PDF",
  "dimensions": [{"w": 4200, "d": 3100, "raw": "4200 x 3100"}],
  "vector": {"outline": [[0,0]], "source": "…", "units": 4},
  "vision": {"ok": true, "model": "…", "plan": {…}},
  "vision_status": {"configured": false, "model": ""},
  "plan": {
    "room": {"w": 4200, "d": 3100, "h": 2700, "wallT": 100,
             "outline": [[0,0],[4200,0],[4200,3100],[0,3100]]},
    "openings": [{"kind":"window","wall":0,"x":800,"w":1500,
                  "z0":900,"z1":2200}],
    "partitions": [{"a":[2000,0],"b":[2000,3100]}],
    "furniture": [],
    "confidence": 0.8,
    "needs_dimensions": false,
    "questions": [],
    "notes": []
  }
}
```

- `plan` — уже проверенный и приведённый к схеме проекта (мм, контур
  переведён в левый верхний угол, проёмы подрезаны по длине стен).
- `furniture` — только **подсказки** (что видно на плане); автоматически
  не ставится.
- Если `needs_dimensions=true`, комната не строится, в `questions` —
  что уточнить у человека.

Файл **не сохраняется** на сервере: разбор в памяти, ответ сразу.

## 3. Vision (картинки и сканы)

`AI_VISION_MODEL` — любая OpenAI-совместимая модель с картинками
(`gpt-4o`, `gemini-2.0-flash` через OpenRouter, `qwen-vl` и т.п.):

```bash
AI_VISION_MODEL=gpt-4o
AI_VISION_BASE_URL=https://api.openai.com/v1
AI_VISION_API_KEY=sk-...
# необязательно:
AI_VISION_TIMEOUT=120
```

Модель получает рендер страницы/картинку и просит строгий JSON: контур,
проёмы, перегородки, мебель, `confidence`, `needs_dimensions`. Ответ
проходит `normalize_plan` — мусор и выдуманные размеры отсекаются.

Без vision всё равно работают: PDF с текстом, DXF, SVG. Для картинки
показывается превью и просьба прислать размеры/PDF.

## 4. Чат

- 📎 в форме чата → выбор файла → загрузка и карточка плана.
- Карточка: превью, формат, размеры, число проёмов/перегородок,
  уверенность, заметки и вопросы.
- **«Новый проект по плану»** — создаёт пустой проект, переносит диалог,
  открывает и показывает предпросмотр комнаты (resize_room + перегородки +
  проёмы). Применение — как обычно, кнопкой «Применить».
- **«Применить в текущий»** — доступно только если в проекте нет мебели:
  иначе план снёс бы существующую расстановку.
- **«Расставить мебель»** — отправляет модели запрос; план едет в контексте
  (`context.plan`), модель расставляет модули/декор инструментами.
- План остаётся в карточке, пока его не уберут кнопкой «Убрать».

## 5. Проверки

- `tests/api.py`: PDF (текст+размеры+превью), SVG (контур), DXF (контур),
  PNG (превью), неизвестный формат → 415.
- `tests/e2e/ai-plan-import.mjs`: SVG через чат → новый проект → preview →
  apply → комната 4200×3100, проект пустой; PNG без vision → «размеры не
  распознаны», кнопка применения недоступна.
- `tools/deploy.sh` ставит `pypdfium2`, `ezdxf`, `python-multipart`.

## 6. Известные ограничения

- DWG не читаем: просим DXF/PDF.
- PDF — одна страница; выбор страницы пока только через API (`page`).
- SVG с группами/`transform` может дать неверный контур.
- Векторные стены PDF не парсим — текст + vision.
- Мебель с плана не расставляется автоматически: сначала комната, затем
  модель/человек.
- Vision-провайдеру уходит изображение плана; ключ только на сервере.
