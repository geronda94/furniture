# 00 — Обзор проекта

## Зачем

Единое место для мебельной работы с ИИ-агентами: от расчёта деталей до видео и
карточек товаров. Цель — превратить разовые расчёты в **повторяемый, проверяемый
процесс**.

## Принципы

1. **Детерминированный движок — источник истины.** ИИ не «считает в голове», а
   вызывает код. Одинаковый вход → одинаковый результат.
2. **Три слоя:** универсальные правила → цеховые → брендовые (см. `AGENTS.md`).
3. **Валидатор — обязателен.** Результат без прохождения валидатора не выдаётся.
4. **Накопительность:** каждый реальный косяк → правило в `docs/` + тест.
5. **Человек в контуре** на входе (замеры) и перед необратимым (раскрой, деньги).

## Чего этот проект НЕ гарантирует

- Реальные неровности помещения (нужны замеры, учитываются допусками).
- Нестандарт, которого нет в правилах (→ становится новым правилом).
- «Всегда и всё правильно» — надёжность растёт по мере накопления правил и тестов.
