# 09 — Превью и рендеры

## Виды визуалов

| Вид | Для чего | Инструмент |
|---|---|---|
| Чертёж (DXF/PDF) | цех, раскрой | CADCraft |
| Схема раскроя (SVG) | раскрой | движок |
| 3D-рендер | клиенту, каталог | Blender |
| Тур (видео) | презентация | Blender |
| Превью/миниатюра | соцсети, карточки | PhotoCraft |

## Рендеры (Blender)

- Статичные виды: 3/4, фасад, торец, крупный план.
- Фон нейтральный; материалы — плоские цвета (задел под текстуры).
- Для быстрых превью — **Workbench**; для «красиво» — **EEVEE**/**Cycles**.
- Разрешения: обзор 2200×1150; фасад 2560×620; крупный 1700×1100.

## Превью (PhotoCraft)

- Постобработка рендера: фон, тень, плашка с названием.
- Массовые превью — через Data Sets (см. `08-product-cards.md`).

## Хранение

Всё лежит внутри папки проекта:

```
projects/<проект>/
├── renders/    ← рендеры Blender (png, mp4)
├── previews/   ← превью/миниатюры
├── cards/      ← карточки товаров
└── video/      ← смонтированное видео
```

## Соглашения по именам

`<проект>_<вид>_v<N>.png` — напр. `kitchen-10m_3q_v2.png`.
