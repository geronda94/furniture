# Глоссарий

| Термин | Значение |
|---|---|
| **ЛДСП** | Ламинированная ДСП — основной материал корпуса и фасадов |
| **МДФ** | Древесноволокнистая плита средней плотности — фасады, фрезеровка |
| **ДВП** | Древесноволокнистая плита — задние стенки (ХДФ/оргалит) |
| **Корпус** | Боковины, крыша, дно, перегородки, задняя стенка |
| **Фасад** | Дверь или лицевая панель ящика |
| **Боковина** | Боковая вертикальная стенка корпуса |
| **Крыша / Дно** | Верхняя / нижняя горизонтальная деталь корпуса |
| **Полка** | Горизонтальная деталь внутри |
| **Перегородка / стойка** | Вертикальная деталь внутри; на неё вешается петля |
| **Цоколь** | Нижняя декоративная планка (закрывает ножки) |
| **Столешница** | Рабочая поверхность сверху |
| **Ножки** | Регулируемые опоры под корпусом |
| **Кромка** | ПВХ/ABS лента на видимых торцах |
| **Присадка** | Сверловка под крепёж/фурнитуру |
| **System 32** | Стандартная сетка отверстий с шагом 32 мм |
| **Конфирмат** | Винт-стяжка 7×50 |
| **Минификс** | Эксцентриковый стяжок Ø15 |
| **Шкант** | Деревянный/металлический штифт Ø8 |
| **Полкодержатель** | Штифт/RAFIX для съёмной полки |
| **Направляющие** | Механизм выката ящика |
| **Скрытые направляющие** | Blum Tandem и аналоги (не видны) |
| **Петля** | Механизм двери (чашка Ø35) |
| **Накладной фасад** | Закрывает корпус снаружи |
| **Вкладной фасад** | Внутри проёма |
| **Раскрой** | Раскладка деталей на листе |
| **Kerf / пропил** | Толщина реза (3,2–4 мм) |
| **Деловой отход** | Обрезки, идущие в дело |
| **ПЕРЕД** | Обозначение видимого (переднего) торца |
| **Секция** | Независимый короб (модуль) |
