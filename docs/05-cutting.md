# 05 — Раскрой

## Параметры (по умолчанию, в `specs/shop-*.yaml`)

- Лист ЛДСП **2750×1830**; ДВП — свой формат.
- Обрез по периметру **12–15 мм**.
- Пропил (kerf) **3,2–4 мм** (пакетная пила до 5).
- Полезная площадь листа = `(лист − 2·обрез)`.

## Правила

1. **Длинные детали** (> полезного размера) — сегментировать.
2. **Направление текстуры:** боковины и фасады — по высоте; текстура должна ложиться
   вдоль длинной оси листа.
3. Деловой отход 10–20%.
4. Мин. размеры заготовок под кромление/присадку.

## Алгоритм

Движок использует **MaxRects (best short side fit)** — укладка с учётом поворотов и
запрета поворота для деталей с направлением текстуры. Целевой КПД ≥ 80%.

## Выход

- `cutting.svg` — схема раскроя по листам (ЛДСП / ДВП / столешница отдельно).
- В отчёте: число листов, КПД.

## Что улучшать

- Гильотинные ограничения (если цех режет только прямыми резами).
- Учёт делового отхода (обрезки в дело).
- Полосовой раскрой с приоритетом деталей одного размера.
