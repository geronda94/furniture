# 40 — Архитектура отрисовки: канвас и превью

Дата: 2026-10-31 (после уточнения: Blender-вид — только в превью модалки).

## Правило

**Главный 3D-канвас** рисует один класс — `BabylonRenderer`
(`apps/web/src/render3d/babylonScene.ts`). У него два стиля:

| Режим UI | Стиль канваса | Камера |
|---|---|---|
| **Полный** | реальные материалы, текстуры, свет, тени | свободная орбита |
| **Каркас** | упрощённый: без текстур, фактический цвет материала | свободная орбита |
| **Чертёж** | тот же упрощённый, что «Каркас» | фиксированная ортокамера, ракурсы, ось «комната/объект» |

Никакого серого clay-шейдера на канвасе нет — это был эксперимент,
который откатили. «Каркас» и «Чертёж» отличаются **только камерой**.

**Превью внутри модалки конструктора** (`ModulePreview`, 2D-движок
`render25d`) — это отдельное маленькое окно. Именно там используется
Blender-подобный вид:

- серые градиенты по граням;
- тонкие контуры;
- без цветных материалов и текстур.

Это тот же визуальный язык, но не второй 3D-рендерер: `ModulePreview` —
2D-canvas, который проецирует детали модуля.

## Видимость и режимы

- Фасады — только по `ui.facades`, одинаково на канвасе и в превью.
- Объектный режим конструктора:
  - камера всегда «Обзор» (орбита вокруг модуля);
  - **вид отрисовки не меняется**: пришли в «Полном» — останется «Полный»,
    в «Каркасе» — «Каркас», в «Чертеже» — «Чертёж» (камера чертежа на время
    конструктора снимается с фиксации, после закрытия возвращается);
  - мини-план скрыт.

## Что убрано

- Clay-шейдер и `applyClayMaterials` из `BabylonRenderer`;
- отдельная цветная «схема» в 3D — заменена прежним упрощённым стилем;
- спецскрытие фасадов по режиму;
- отдельный путь отрисовки для объектного режима.

## Что осталось вспомогательным

- `render25d` — план, развёртки стен, миниатюры и превью конструктора;
- стиль `clay` в `render25d` используется только превью (ModulePreview).

## Правила на будущее

1. Новый вид канваса — стиль в `BabylonRenderer`, не второй 3D-рендерер.
2. Blender-подобный clay — только в превью; канвас не перекрашивать.
3. Видимость (фасады, комната, фурнитура) — из `ui.*`, не из режима.
4. Объектный режим не должен менять выбранный пользователем вид.
