# 01 — Правила проектирования (универсальные)

> Универсальный слой. Цеховое — в `specs/shop-*.yaml`, брендовое — `specs/hardware-catalog.md`.

## Обозначения

`W` — ширина корпуса, `H` — высота, `D` — глубина, `t` — толщина плиты (16/18 мм),
`tb` — толщина ДВП (3/4 мм).

## 1. Деталировка

Главное правило: **вкладная деталь = чистовой размер минус 2 толщины (−2t)**.

| Деталь | Размер | Кол-во | Примечание |
|---|---|---|---|
| Боковина | `D × H` (вкладная крыша) / `D × (H−t)` (накладная) | 2 | передний торец — видимый |
| Крыша / Дно | `(W−2t) × D` | 1+1 | у каждой секции своя |
| Полка съёмная | `(W−2t−3) × (D−20)` | n | зазор 3 мм |
| Полка фиксированная | `(W−2t) × D` | n | |
| Перегородка / стойка | `D × (H−2t)` | n | **только явно заданная** (не по числу дверей) |
| Задняя стенка (ДВП) | `(W−2) × (H−2)` | 1 | набивная |
| Фасад | см. §3 | n | кромка 2 мм по периметру |
| Цоколь | `(W−2t) × h` | 1 | сегментируется |

## 2. Секции — независимые модули

- Каждая секция — **отдельный короб**: свои 2 боковины, **своя крышка**, своё дно,
  свой задник, свои опоры.
- **Общих (совмещённых) стенок нет** — на стыке двух секций стоят обе стенки (двойная, 32 мм).
- **Перегородка не добавляется автоматически по числу дверей.** Две створки
  вешаются на крайние боковины; средняя стойка нужна только по конструкции
  (полки/жёсткость) и задаётся отдельным параметром `dividers`.
- Если перегородка нужна — она идёт на всю внутреннюю высоту корпуса.

## 3. Зазоры фасадов

- Между соседними фасадами **2–3 мм** (по умолч. 3).
- По бокам 1,5–2 мм; сверху/снизу 1,5–2 мм; от столешницы 4–5 мм.
- Накладной фасад: `H_ф = H − зазор_верх − зазор_низ`;
  `W_ф = (W − 2·зазор_бок − (n−1)·зазор_между) / n`.
- Вкладной фасад = проём − 4 мм.
- ГОСТ 16371: двери ≤2 мм, ящики ≤1,5 мм.

## 4. Фасады — предельные размеры

- **Дверь ≤ 600 мм** (иначе делить на несколько).
- **Фасад ящика ≤ 900 мм.**
- Превышение → **авто-деление** движком.

## 5. Длинные детали

Деталь длиннее формата листа (напр. цоколь 10 м, столешница) — **сегментировать**
по полезному размеру листа + стык.

## 6. Опоры

- Корпус стоит на **регулируемых ножках** (обычно 4 на секцию) + цоколь спереди.
- Ножки — закупные, в деталировку как ЛДСП не идут.
