## 2. Что сделано в этой сессии

### Модалка и объектный режим
- Одна модалка объекта: быстрый режим + «Детали и конструктор».
- Быстрый режим — **маленькое окно рядом с курсором**, без камеры и без
  отдельного большого предпросмотра.
- «Детали и конструктор» — **объектный режим**: окно справа (~58% 3D-канваса),
  крупная схематичная картинка слева, боковое меню с вкладками.
- В объектном режиме камера сохраняет прежнюю позицию при входе, смотрит на
  объект анфас, вращается **вокруг объекта**; при выходе камера возвращается.
- Клик по фасаду/ящику не открывает/не закрывает окно: появляется маленькая
  круглая иконка у детали, открывает/закрывает её. Клик по корпусу при закрытом
  окне снова открывает быстрое окно.
- Клик по объекту в 3D/дереве не двигает камеру; камера двигается только в
  объектном режиме.

### Размеры и детали
- Схематичный ч/б предпросмотр без текстур.
- Подсветка выбранной детали.
- Размеры: собственные, до соседних полок/крышки/дна, до границ модуля,
  кромка в карточке.
- Размеры на главном 3D-канвасе, переключатель «Размеры».
- Вкладка «Материалы» в конструкторе.

### Комнаты, окна, двери
- Проёмы и перегородки тянутся на плане; координаты и сдвиг — в свойствах.
- Дерево: Стены / Проёмы / На стенах / Группы и комнаты / Мебель.
- Настройки проёмов: ширина, смещение, Z, петли, угол, открытие.
  Исправлен баг `NumField` → обработчики получали Event вместо числа.

### Библиотеки и цены
- `specs/materials.yaml`: ЛДСП, штукатурка, паркет/ламинат, столешницы, задники.
  UI: «Материалы → библиотека…», своя текстура файлом/URL.
- Больше пресетов мебели и проёмов.
- `specs/pricing.yaml`: материалы (м² + запас), раскрой, кромка, фурнитура,
  сборка, наценка, партнёрская комиссия. Смета в `solve().cost`, вкладка
  «Смета», итог в статус-баре.
- `specs/partners.yaml` — заготовка партнёров/лидов.

### История
- `project.log` — сохраняемый журнал изменений.
- `HistoryPanel` («Журнал»), Ctrl+Z/Ctrl+Shift+Z в рамках сессии.
- Undo-снимки **не сохраняются** между перезагрузками; лог сохраняется.

### Ящики/фурнитура
- Передняя стенка короба под фасад (отдельная панель).
- `side_extra`: борта выше переда/зада на 10 мм у скрытых направляющих.
- Крепление направляющих снизу — в присадке.
- Широкие ящики делятся на отдельные короба.

## 4. Запуск локально

```bash
cp .env.example .env
# задать POSTGRES_PASSWORD
docker compose up -d --build
# web http://localhost:5176, api http://localhost:8003/api/health
```

Без Docker:

```bash
uvicorn apps.api.main:app --reload --port 8000
cd apps/web && npm run dev
```

## 5. Перенос на сервер

- Код — через GitHub (`git@github.com:geronda94/furniture.git`).
- `.env` — **не через GitHub**: скопировать вручную (`scp`) в `~/projects/furniture/.env`.
- На сервере: `docker compose up -d --build`, проверить `/api/health` и `:5176`.
- Vite-хост: `5176.it2b.top` и поддомены `.it2b.top` разрешены в
  `apps/web/vite.config.ts`; дополнительные — через `VITE_ALLOWED_HOSTS=host1,host2`.
- Пароль БД в `compose.yaml` берётся из `.env`; в репозитории только `.env.example`.

## 6. Подводные камни / известные ограничения

1. **Demo-проект** на диске — 1 модуль «Тумба 800» (3600×2800). Старая
   многосекционная версия из браузера не сохранилась в файл; если она нужна —
   поднять из браузерной сессии/бэкапа.
2. **Undo** живёт в памяти вкладки; после перезагрузки остаётся только журнал.
3. **Материалы/цены** — defaults из `specs/*.yaml`; под конкретный цех менять там.
4. **Партнёрская логика** — только комиссия в смете + YAML; CRM/лиды не сделаны.
5. **Объектный режим камеры** — сохраняет/восстанавливает позицию, но при
   переключении между объектами внутри режима цель меняется; проверить на
   сервере с реальным GPU.
6. **Планы** — перетаскивание проёмов/перегородок работает в развёрнутом плане;
   на мини-плане может быть мелко.
7. **Docker**: `Dockerfile.api` запускает uvicorn с `--reload`; для продакшена
   лучше убрать `--reload`.
8. **node_modules** в Docker named volume; при обновлении package.json может
   понадобиться `docker compose build --no-cache web`.
9. **Секреты**: в коде/репозитории ключей нет. Пароль БД — только `.env`.
