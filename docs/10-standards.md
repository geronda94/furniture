| Раскрой | MaxRects (best short side fit) |

## Архитектурные решения

1. **Детерминированный движок = источник истины.** ИИ вызывает код, не считает сам.
2. **Три слоя правил:** универсальные (docs) / цеховые (specs) / брендовые (specs).
3. **Каждая секция — независимый модуль** (свои стенки + **своя крышка**); общих стенок нет.
4. **Перегородка — только по конструкции или явному запросу** (`dividers`); две двери не требуют средней стойки.
5. **Кромка только на видимые торцы**; видимый торец = `ПЕРЕД`.
6. **Длинные детали сегментируются** по формату листа.
7. **В Blender каждый элемент — отдельный объект** (не склеивать по материалу).
8. **Валидатор обязателен** перед выдачей.
