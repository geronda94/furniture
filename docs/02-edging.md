# 02 — Кромкование (видимость торцов)

> Кромка ставится **только на видимые торцы**. Скрытое (за фасадом, сзади, внутри) — без кромки.

## 1. Толщины кромки

- **0,4 / 1 / 2 мм.** Фасады — **2 мм**; внутренние видимые — 1–2 мм; скрытое — нет.
- Ширина кромки = толщина плиты + 3–4 мм (16 → 19–20).
- Соседние детали утапливаются на толщину кромки (эффект «лесенки»).

## 2. Пильный размер

```
пильный = чистовой − (кромка_лево + кромка_право)   по X
пильный = чистовой − (кромка_верх + кромка_низ)     по Y
```

## 3. Что кромкуется (стандарт)

| Деталь | Кромка | Почему |
|---|---|---|
| Фасад (дверь, ящик) | 2 мм по периметру | виден целиком |
| Наружные торцы крайних секций | 2 мм на переднем торце | видно сбоку |
| Внутренние боковины/перегородки | **нет** | закрыты фасадом |
| Крыша / Дно | **нет** | скрыты фасадом/столешницей |
| Полки за дверью | **нет** | скрыты |
| Задняя стенка (ДВП) | нет | скрыта |
| **Ящик**: боковины и задняя стенка | **2 мм на верхнем торце** | видно при открытии |
| Ящик: дно | нет | не торец |
| Цоколь | 0,4 мм на переднем торце | виден |

## 4. Обозначение

Видимый торец помечается **`ПЕРЕД`** (а не Л/В/П/Н, чтобы не путать ориентацию).
Пример: `Боковина: ПЕРЕД2` — передний торец в кромке 2 мм.

## 5. Открытые секции

Если секция без фасада (открытая) — её передние торцы корпуса и полок **видны** →
кромка 1–2 мм.

## 6. Не закрыто правилами (нужен домен)

- какой торец «передний» у нестандартных/косых деталей;
- направление текстуры на радиусных деталях;
- кромка постформингованной столешницы (кромка интегрирована — не кромкуется).
