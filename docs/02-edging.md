# 02 — Кромкование (видимость торцов)

> Кромка ставится на **любой торец, не закрытый другой деталью**. Фасад не считается крышкой: при открытой двери торец виден. Закрыто = примыкает крыша, дно, задник или соседняя панель.

## 1. Толщины кромки

- **0,4 / 1 / 2 мм.** Фасады — **2 мм**; внутренние видимые — 1–2 мм; скрытое — нет.
- Ширина кромки = толщина плиты + 3–4 мм (16 → 19–20).
- Соседние детали утапливаются на толщину кромки (эффект «лесенки»).

## 2. Пильный размер

```
пильный = чистовой − (кромка_лево + кромка_право)   по X
пильный = чистовой − (кромка_верх + кромка_низ)     по Y
```

## 3. Что кромкуется (стандарт)

**Правило:** кромка ставится на **любой торец, который не закрыт другой
деталью**. Вкладной или накладной каркас меняет, кто кого накрывает: при
вкладном крыша/дно между боковинами (торцы боковин открыты), при накладном —
наоборот (боковые торцы крыши/дна открыты).

| Деталь | Кромка | Почему |
|---|---|---|
| Фасад (дверь, фасад ящика) | 2 мм по периметру | виден целиком |
| Боковина | 2 мм на **переднем** торце всегда | передний торец не закрыт |
| Боковина, **вкладной** каркас | 2 мм на **верхнем и нижнем** торцах | крыша/дно вложены между боковинами — торцы открыты |
| Боковина, **накладной** каркас | верх/низ — нет | крыша/дно накрывают боковины |
| Боковина | 0.4 мм на **заднем** торце, если **нет задника** | иначе закрыт задником |
| Перегородка | перед 2 мм; верх — без крыши; зад — без задника; верх/низ под крышей и дном — нет | вложена между крышей и дном |
| Крыша / Дно | 2 мм на **переднем** торце | не закрыт другой деталью |
| Крыша / Дно, **вкладной** | боковые торцы — нет | закрыты боковинами |
| Крыша / Дно, **накладной** | 2 мм на **боковых** торцах | накрывают боковины, торцы видны |
| Крыша / Дно | 0.4 мм на заднем торце, если нет задника | иначе закрыт |
| Полка | 2 мм на **переднем** торце всегда | виден при открытой двери/в открытой секции |
| Полка | 0.4 мм на заднем торце, если нет задника | иначе закрыт |
| Царга | 2 мм на переднем торце; 0.4 сзади без задника | видна изнутри |
| Задняя стенка (ДВП/ЛДСП/картон) | нет | закрывает корпус, торец скрыт |
| Ящик: боковины/стенки | верхний торец 0.4 мм; остальные — нет | верх виден внутри, торцы примыкают к другим стенкам |
| Ящик: дно | нет | не торец |
| Цоколь | 0.4 мм на переднем торце | виден |
| Столешница-постформинг | перед — нет | кромка интегрирована |

Толщина: **2 мм** — видимые наружные/передние торцы, **0.4 мм** — скрытые, но
открытые внутрь (зад без задника). Тип кромки (ПВХ/ABS/лазер) — в
`specs/edge-types.yaml`; цвет и «ПЕРЕД» показываются в деталировке и на карте.

## 4. Обозначение

Видимый торец помечается **`ПЕРЕД`** (а не Л/В/П/Н, чтобы не путать ориентацию).
Пример: `Боковина: ПЕРЕД2` — передний торец в кромке 2 мм.

## 5. Открытые секции

Открытая секция ничего не меняет в правилах: передние торцы боковин, крыши/дна
и полок уже кромкуются, потому что они не закрыты. Фасад не является «крышкой»
для торца — при открытой двери торец виден.

## 6. Не закрыто правилами (нужен домен)

- какой торец «передний» у нестандартных/косых деталей;
- направление текстуры на радиусных деталях;
- кромка постформингованной столешницы (кромка интегрирована — не кромкуется).

## 7. Переопределения кромки (человек / ИИ)

Правила выше — значения по умолчанию. Их можно менять на уровне модуля:

```json
{
  "edges": {
    "visible": "abs_2",
    "hidden": "pvc_04",
    "byPart": {
      "Полка": { "front": "none", "back": "pvc_2" },
      "Боковина*": { "top": "none" }
    }
  }
}
```

- `visible` / `hidden` — заменить тип кромки для всех существующих видимых
  (≥1.5 мм) или скрытых (<1.5 мм) торцов.
- `byPart` — по имени детали; `*` на конце — префикс. Стороны: `left`, `right`,
  `top`, `bottom` или `front`/`back` (относительно `ПЕРЕД`).
- Значение: `auto` (оставить правило), `none` (убрать кромку), `pvc_2`,
  `pvc_04`, `abs_2`, `laser_1`.
- Можно и **добавить** кромку туда, где правило её не ставило.
- Тип хранится в `Part.edge_kind` и участвует в слиянии деталей; пильный размер
  пересчитывается от толщины выбранного типа.
- В 2D-карте полоса кромки вынесена за контур пласти (это обозначение торца), а
  в интерактивной 3D-детали кромка показана на площади торца.

UI: «Корпус» — типы видимой/скрытой кромки; «Деталь» — селектор по каждой из
четырёх сторон. Данные хранятся в `params.edges`, поэтому ИИ может менять их
тем же JSON.
