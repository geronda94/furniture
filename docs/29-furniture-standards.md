## 2. Что проверяет валидатор

### Кухня (напольные модули со столешницей)

| Код | Уровень | Правило |
|---|---|---|
| `std-worktop-height` | error <800 / >920, warning вне 850–900 | высота рабочей поверхности `z + цоколь + H + столешница`; ГОСТ 13025.1 — 850–900 |
| `std-base-height` | warning | корпус 700–750 мм (при цоколе >0) |
| `std-base-depth` | warning | глубина 500–600 мм (при цоколе >0) |
| `std-plinth` | error <80, warning вне 100–150 | цоколь: ГОСТ ≥80, практика 100–150 |
| `std-wall-gap` | warning | зазор столешница → низ навесных 450–750 (EN 1116: 500–600) |

### Навесные шкафы

| Код | Уровень | Правило |
|---|---|---|
| `std-wall-height` | error <1100, warning вне 1350–1500 | низ навесных от пола |
| `std-wall-top` | error > потолка, warning >2200 | верх навесных |
| `std-wall-depth` | warning | глубина 280–360 мм (ГОСТ: внутренний ≥270) |

### Корпус и фасады

| Код | Уровень | Правило |
|---|---|---|
| `std-door-width` | error | створка > 600 мм — делить (ГОСТ 16371, практика EN) |
| `std-drawer-width` | error | фасад ящика > 900 мм |
| `std-shelf-span` | error >1100, warning >900 (16 мм) / 1000 (18 мм) | пролёт полки с учётом стоек (`dividers`) |
| `std-tip-over` | warning | модуль ≥1800 мм не у стены — обязательное крепление (EN 14749) |

### Мягкая мебель и кровати (ГОСТ 13025.2)

| Код | Правило |
|---|---|
| `std-bed-size` | ширина 700/800/900 или 1100–1800, длина 1860–2050 мм |
| `std-seat-depth` | диван 800–1000, кресло 780–1000 мм (габаритная глубина) |
| `std-seat-width` | кресло ≥480, диван ≥1000 мм |

### Столы и стулья (ГОСТ 13025.3)

| Код | Правило |
|---|---|
| `std-table-height` | обеденный 700–780, журнальный 350–500 мм |
| `std-chair-height` | 800–950 мм (без барных) |

## 3. Что сознательно не автоматизировано

- Прочность и ударные испытания (ГОСТ 16371, EN 14749) — это стенд, не геометрия.
- Точная эргономика посадки (высота сиденья, наклон спинки) — в модели
  нет этих параметров; контролируем габариты и диапазоны.
- Пожарные/санитарные требования к материалам — зона поставщика плиты.
- Неровности стен — монтажный допуск, отдельный слой (см. `docs/15`).

## 4. Как исправлять

1. `GET /api/projects/{id}/layout` или `python3 tools/validate_project.py`.
2. Ошибки `std-*` — блокируют strict-PUT и выдачу.
3. Warning — разобрать: либо исправить размер, либо осознанно принять
   (например, диван 1050 мм глубиной с дополнительными подушками).
