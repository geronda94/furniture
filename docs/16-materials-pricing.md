# 16 — Материалы, цены и смета

## Библиотека материалов

`specs/materials.yaml` — данные, не правила. Категории:

- ЛДСП / декоры
- Штукатурка / стены
- Паркет / ламинат
- Столешницы
- Задние стенки

Поля: `id`, `name`, `color`, `accent`, `pattern` (`solid|wood|stone|metal`),
`texScale`, `price_m2`, необязательный `texture_url`.

В интерфейсе: `Проект → Материалы проекта` или вкладка «Материалы» у модуля.
Можно выбрать декор, загрузить свою текстуру файлом или указать URL. Текстура
кладётся в `material.texture` и сохраняется в проекте (data URL или ссылка).

- `project.materials` — базовые материалы по ролям.
- `project.materialVars` — глобальные переменные материалов: декор + части
  (каркас, боковины, полки, ящики, фасады, задник, столешница, цоколь, опоры)
  + охват (все / напольные / навесные). Одна переменная может применяться к
  нескольким частям сразу.
- Приоритет: материалы проекта → переменные → материалы модуля.
- `instance.materials` — переопределения только для модуля; «к проекту»
  возвращает унаследованный материал.
- Глобальные переменные проекта (`project.globals`) задают толщину, задник,
  каркас, фурнитуру и зазоры; ручная правка поля у модуля создаёт
  `instance.overrides`.

## Смета: рынок → цех → поставщик

Цены больше не один файл «в рублях». Три слоя:

| Слой | Где | Что задаёт |
|---|---|---|
| Рынок | `specs/markets.yaml` + `specs/pricing/<market>.yaml` | страна, валюта, локаль, НДС, базовые цены |
| Цех | `specs/shops.yaml` | формат листа, пропил/обрез, раскрой, кромка, сборка |
| Поставщик | `specs/suppliers.yaml` | цены петель/направляющих/патронов, коэффициент ручек |

Значения — **стартовые (заготовка)** и помечены `source`/`draft`; их нужно
сверить с конкретным цехом. Добавить страну = строка в `markets.yaml` +
прайс по образцу `specs/pricing/template.yaml`.

Проект хранит `market`, `shop`, `supplier`; смена любого поля пересчитывает
сметы всех модулей. Приоритет: прайс рынка → переопределения цеха → поставщик.

`specs/pricing.yaml` (RUB) остаётся legacy-прайсом для старых вызовов и как
fallback, если для рынка нет файла.

### Что в `cost`

```
cost.currency / locale / symbol   — валюта и формат
cost.market / shop / supplier     — выбранные слои
cost.vat_percent / vat            — НДС
cost.total                        — до НДС
cost.total_with_vat               — к оплате
cost.draft / source / updated     — честность цены
cost.lines[]                      — материал, раскрой, кромка по типам,
                                    петли, направляющие, опоры, ручки,
                                    крепёж, полкодержатели, патроны, сборка
```

Кромка считается по **типу** (`pvc_04`, `pvc_2`, `abs_2`, `laser_1`) из
`edge_plan`, а не только по толщине. Крепёж и полкодержатели берутся из
фактических операций присадки.

В интерфейсе: вкладка «Смета» у модуля, КП (`QuotePanel`) и итог в статус-баре
показывают валюту рынка и НДС; «цены-заготовка» помечаются бейджем.
Настройка — `Проект → Цены и рынок`.

## Партнёры

`specs/partners.yaml` — заготовка: партнёр, город, услуги, комиссия, контакты,
статусы лида (`new → sent → quoted → won/lost`). Комиссия уже учитывается в
смете; передача лида и CRM — следующий этап.
