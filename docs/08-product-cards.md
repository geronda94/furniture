# 08 — Карточки товаров

> Карточки для маркетплейсов/каталога: массово, из одного шаблона + данных.

## Ключевая возможность: PhotoCraft Data Sets (аналог Photoshop Variables)

PhotoCraft умеет **подставлять данные в шаблон** — один дизайн → сотни карточек.

Команды движка:

| Действие | Команда |
|---|---|
| Определить переменную | `image.variables.define` |
| Задать наборы данных | `image.variables.dataSets` |
| Импорт CSV | `file.import.variableDataSets` |
| Применить набор | `image.applyDataSet` |
| Экспорт по файлу на строку | `file.export.dataSetsAsFiles` |

MCP-инструменты: `photocraft_doc_import_data_sets`, `photocraft_doc_export_data_sets`.

## Поток

```
Шаблон карточки (.pcraft) + CSV (SKU, название, размеры, цена, фото)
   └─► PhotoCraft applyDataSet
        └─► экспорт: projects/<проект>/cards/<SKU>.jpg
```

## Что должно быть на карточке

- Рендер изделия (из Blender) — на белом/нейтральном фоне.
- Название, габариты (Ш×В×Г), материал, цвет.
- Цена / артикул.
- Логотип/бренд, единый стиль.

## Пайплайн

1. **3D-рендер** изделия → `projects/<проект>/renders/`.
2. **Шаблон** карточки (PhotoCraft) → `assets/` или `projects/<проект>/cards/_templates/`.
3. **Данные** (CSV) → `projects/<проект>/cards/data.csv`.
4. **Пакетный экспорт** → `projects/<проект>/cards/`.

## Открытые вопросы

- Единый визуальный стиль карточек (сетка, шрифты, цвета).
- Форматы: маркетплейс (1:1, 3:4), сайт, соцсети.
- Требования площадок (размеры, водяные знаки).
