# 18 — Крепёж, соединения и правила выбора

> Данные — `specs/hardware.yaml` (`fasteners`), правила — этот документ.
> Тип крепежа выбирает **конструкция**, а не «что красивее». Человек и ИИ
> могут переопределить тип, но обязаны понимать последствия.

## 1. Что где применяется

| Соединение | По умолчанию | Альтернативы | Когда менять |
|---|---|---|---|
| Боковина ↔ крыша/дно | Евровинт/эриксон 7×50 | минификс, шканты | минификс — если головка не должна быть видна; шканты — только с клеем и стяжкой |
| Боковина ↔ перегородка | Евровинт 7×50 | минификс | то же |
| Крыша/дно ↔ перегородка | Евровинт 7×50 | минификс | скрытый крепёж |
| Фасад ящика ↔ короб | Саморез 4×30 изнутри | — | стандарт; 4 шт на фасад |
| Задняя стенка | Скобы/саморезы 4×16 | — | по материалу задника |
| Петли | Чашка Ø35 + планка | — | по бренду петли |
| Полкодержатели | System 32 Ø5 | фиксатор, минификс, шкант | по типу полки |
| Ручки | Винт ручки сквозь фасад | — | по типу ручки |
| Столешница | Саморезы/уголки изнутри | — | по столешнице |
| Опоры/колёса | По схеме `legs`: площадка/втулка/пятка | — | выбрать `legMount` |
| Газовый патрон | По шаблону производителя | — | всегда сверять шаблон |

**Почему евровинт по умолчанию:** высокая прочность на вырыв, простой монтаж,
не требует клея и струбцин. **Минификс** — когда головка не должна быть видна
(открытые бока, дизайнерские фасады) и допустима разборка. **Шканты** — только
позиционирование + клей + стяжка; сами по себе корпус не держат.

## 2. Классы соединений

- `carcass` — боковины ↔ крыша/дно.
- `divider` — крыша/дно ↔ перегородка.
- `drawer` — фасад ящика ↔ короб.
- `leg_mount` — опора/колесо ↔ дно (не соединение корпуса, а присадка).

Для класса можно задать отдельный крепёж; иначе используется общий выбор.

## 3. Параметры модуля (JSON)

```json
{
  "fastener": "auto",
  "hiddenFasteners": false,
  "connectionOverrides": {
    "carcass": "minifix",
    "divider": "confirmat"
  },
  "legMount": "leg-plate-60"
}
```

- `fastener`: `auto` | `confirmat` | `minifix` | `dowel` | `screw-4x30`.
- `hiddenFasteners: true` — в режиме `auto` выбирает минификс вместо евровинта.
- `connectionOverrides` — точечно по классу; `auto`/пусто — наследовать.

Движок возвращает:

```
hardware_plan.fasteners  — всего крепежа корпуса (шт)
hardware_plan.screws     — саморезы фасадов ящиков
hardware_plan.joints[]   — { joint, class, fastener, fastener_id, count }
operations[]              — каждое отверстие с joint/joint_class/hardware
```

## 4. Как должен думать ИИ

1. Не выдумывать крепёж: брать `id` из `specs/hardware.yaml.fasteners`.
2. По умолчанию не менять `fastener: auto`.
3. Минификс — только по запросу «скрытый крепёж» или если торец/головка
   видимы; иначе евровинт.
4. Шканты — только вместе с клеем и стяжкой; не предлагать как единственный
   крепёж корпуса.
5. Саморезы — для фасадов ящиков, задника, столешницы; не для несущих
   соединений корпуса.
6. Любое изменение — через `params`, затем `solve`; проверять
   `hardware_plan.joints` и `requires_pattern`.
7. Заводские шаблоны (скрытые направляющие, газовые патроны) не додумывать:
   `requires_pattern: true` остаётся, пока нет данных.

## 5. UI

- «Корпус»: крепёж корпуса, скрытый крепёж, кромка видимая/скрытая.
- «Сборка»: список соединений с крепежом и количеством; переопределение для
  корпуса/перегородок; чек-лист сборки с прогрессом.
- Карта детали: каждое отверстие показывает крепёж, назначение и координаты.
