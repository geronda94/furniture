# 07 — Видео-пайплайн

> Для контента по мебели: обзоры, реклама, презентации изделий.

## Инструменты

| Инструмент | Для чего | MCP |
|---|---|---|
| **Blender** | 3D-анимации, туры, рендер-видео | `blender` |
| **Kdenlive** | Монтаж, нарезка, субтитры | `kdenlive` |
| **FilmCraft** | Аналог Premiere: склейка, эффекты | `filmcraft` |
| **EffectCraft** | Моушн (аналог AE): титры, графика | `effectcraft` |
| **SoundCraft** | Озвучка, музыка | `soundcraft` |
| **DeckCraft** | Презентации/слайды | `deckcraft` |

## Типовые задачи

1. **Тур по изделию** — Blender (`blender_build.py ... tour`) → `projects/<проект>/video/`.
2. **Ролик-обзор** — тур + титры (EffectCraft) + озвучка (SoundCraft) → монтаж (Kdenlive).
3. **Презентация клиенту** — DeckCraft: рендеры + деталировка + КП.
4. **Шортсы/вертикаль** — вертикальный кроп тура + субтитры.

## Соглашения

- Черновой монтаж — в `projects/<проект>/video/draft/`, финал — `.../final/`.
- Исходники (рендер-секвенции) — в `projects/<проект>/renders/`.
- Имена: `<проект>_<тип>_v<N>.<ext>` (напр. `kitchen-10m_tour_v2.mp4`).

## Пайплайн (черновой)

```
Blender (тур/рендер) ──► projects/<проект>/renders/
   └─► EffectCraft (титры, плашки) ──►
        └─► SoundCraft (озвучка/музыка) ──►
             └─► Kdenlive (монтаж, экспорт) ──► projects/<проект>/video/final/
```

## Открытые вопросы

- Шаблон титров/интро для мебельных роликов.
- Библиотека музыки/звуков.
- Автоматизация: скрипт «Blender-тур → монтаж в Kdenlive».
