## 4. Что осталось / ограничения

- Посадка считается по центру декора, без отдельных якорей «место сидения»
  и без анимации; для кровати — один вариант «лежать».
- Настенные выключатели работают, если они есть в проекте (`wallItems`);
  в демо-квартире их нет — проверялись на торшере и мойке.
- Закрытость двери определяется углом открытия (`angle > 30°` — проход).
- Прогулка и полёт вырезаны из интерфейса, код обоих сохранён и описан в
  `docs/39-walk-disabled.md`. В объектном режиме конструктора камера всегда обзор.
- «Каркас» и «Чертёж» используют один clay-шейдер; разница только в камере.
  Плотность/контраст градиента при желании выносится в настройки.
- **Превью в модалке конструктора** (объект и детали) переведено на clay-вид: серый градиент и лёгкие контуры, без цветных материалов. Это и был исходный запрос «как в Blender». Канвас при этом остался в прежнем упрощённом стиле.
- **Фасады** показываются всегда, если их не выключить кнопкой «Фасады» —
  режим отрисовки их больше не скрывает.
- **Объектный режим** конструктора не меняет выбранный вид: пришли в
  «Полном» — остаётся «Полный», и т.д. Камера — всегда орбита вокруг модуля.
- Архитектура отрисовки: `docs/40-render-architecture.md` — один
  `BabylonRenderer`, два стиля (`full` / `clay`), «Чертёж» — clay + фикс. камера.
- 2D-развёртки стен оставлены как отдельный лёгкий режим без WebGL.
