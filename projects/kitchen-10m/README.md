# kitchen-10m — кухня на 6 секций, 10 м

Демонстрационный проект. Проверка движка, правил кромкования, стыков, 3D-сборки.

## Вход

```
--sections "1600:2:1:Тумба с ящиком,1700:2:0:Мойка,1600:0:3:Ящики,
            1700:2:0:Тумба,1600:0:3:Ящики,1800:2:0:Тумба"
```
- 6 секций, суммарная длина **10 000 мм**
- корпус 720×560, цоколь 100, столешница 38, ЛДСП 16
- каркас: **`inset`** (вкладная — по умолчанию, самое распространённое)

## Результат

- **124 детали**, 13 листов ЛДСП, КПД раскроя ~85 %
- перегородки под каждую дверь, полки по отсекам, 24 ножки
- фасады авто-поделены (дверь ≤600, ящик ≤900)
- **пересечений деталей нет** (проверяется движком)

## Файлы (в этой папке)

| Файл | Что |
|---|---|
| `parts.csv`, `parts.xlsx` | деталировка |
| `cutting.svg` | схема раскроя |
| `scene3d.json` | 3D-данные для Blender |
| `kitchen.blend` | 3D-сцена (объекты по деталям, анимация) |
| `kitchen_facade.dxf`, `kitchen_parts.dxf` | чертежи для CADCraft |
| `report.txt` | отчёт + валидация |
| `parts.json` | машинная деталировка |
| `NOTES.md` | разбор: что нашли и доработали |

## Медиа

Рендеры и видео — в `renders/` этого проекта:
3/4 (закрыто/открыто), фасад, торец, анимация открытия, тур камерой, чертежи.

## Как пересобрать

```bash
cd tools
python3 kitchen.py --sections "1600:2:1:Тумба с ящиком,1700:2:0:Мойка,1600:0:3:Ящики,1700:2:0:Тумба,1600:0:3:Ящики,1800:2:0:Тумба" --out ../projects/kitchen-10m
blender -b -P blender_build.py -- ../projects/kitchen-10m/scene3d.json ../projects/kitchen-10m/renders tour
```
