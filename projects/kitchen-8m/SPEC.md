# kitchen-8m — спецификация (на согласование)

- Длина **8000 мм**, высота **2700 мм**.
- Глубина: низ/пеналы **560**, верх **350**.
- Цоколь 100, столешница 38, ЛДСП 16, ДВП 4.

## Верхний уровень (3-й, подвесной)
- Высота **1200** (1500…2700), глубина 350.
- Делится на 2:
  - **нижний подуровень 300 мм** — дверцы **открываются вверх** (flap), внутри полки;
  - **верхний подуровень 900 мм** — распашные дверцы.
- Общий вид: полки внутри, задняя стенка.

## Техника (заглушки в 3D)
- Духовка + микроволновка — в пенале секции 1 (ниши).
- Плита — на столешнице секции 2 (+ вытяжка над ней).
- Мойка — в столешнице секции 3.
- Посудомойка — фасадная панель секции 4.
- Холодильник — ниша в пенале секции 6.

## Правила (из проекта)
- Каждая секция — отдельный модуль; своя крышка/дно/стенки.
- Каждой двери — своя стойка; полки — по отсекам.
- Кромка только на видимых торцах.
- Без пересечений деталей (проверяется движком).
- Накладная/вкладная схема — параметр (`inset` по умолчанию).
