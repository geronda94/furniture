# assets/ — библиотека ресурсов

```
assets/
├── materials/   ← материалы (декор ЛДСП/МДФ, цвета)
├── textures/    ← текстуры (декоры, кромка, металл)
└── hardware/    ← 3D-модели фурнитуры (петли, направляющие, ручки)
```

## Правила

- Имена — латиницей, с указанием типа: `ldsp_oak_natural.jpg`, `handle_bar_128.stl`.
- Материалы (декоры) — с указанием кода/названия производителя.
- 3D-модели фурнитуры — низкополигональные (для сборки в Blender).
- Источник и лицензия — в `assets/SOURCES.md` (создать при первом импорте).
